# Destination artwork provenance

These two 512 x 512 PNG files are original, offline Questory assets generated
with OpenAI's built-in image generation tool on 4 September 2026. They were
downsampled from the generated masters for mobile bundle size and are not copied
from an external template, photograph, brand, or map provider.

## `nha_trang_coast.png`

Prompt summary: original square flat editorial illustration of Nha Trang's Tran
Phu beachfront, a simplified Tram Huong Tower silhouette, sea and wave shapes, a
curved coral running path, and a small anonymous runner. Screen-printed sticker
style, subtle paper grain, Questory's teal/coral/cobalt/yellow/ink/paper palette,
solid colors only; no text, logos, watermark, photorealism, gradients, map labels,
or UI frame.

## `ho_chi_minh_city.png`

Prompt summary: original square flat editorial illustration of a Ho Chi Minh
City river route, simplified modern and colonial-inspired skyline shapes, leafy
street trees, a coral running path, and a small anonymous runner. Screen-printed
sticker style paired with the Nha Trang asset, subtle paper grain, Questory's
solid-color palette; no text, logos, watermark, photorealism, gradients, map
labels, or UI frame.

The generated masters remain outside the repository. The optimized copies in
this folder are the application deliverables.
